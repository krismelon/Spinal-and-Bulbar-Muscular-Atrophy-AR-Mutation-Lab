# Laboratory Overview
This repository contains the sequence analysis and documentation for a Cell and Molecular Biology Laboratory activity investigating how DNA mutations can affect protein products and contribute to human disease.

The activity focuses on the AR gene and the documented c.2296G>A (p.Ala766Thr) variant, as well as an artificial mutation created for comparison.

# Reference Sequences
The WT AR coding sequence was obtained from the NCBI RefSeq transcript NM_000044.6.

Reference protein:** NP_000035.2

The WT AR CDS is 2,763 bp and produces a predicted androgen receptor protein of 920 amino acids.

# Documented Mutation
The documented AR mutation used in this laboratory activity is c.2296G>A (p.Ala766Thr).

This mutation changes one nucleotide, replacing G with A at coding position c.2296. The nucleotide substitution changes alanine at amino-acid position 766 to threonine. Because only one nucleotide was changed, the reading frame remained unchanged and the mutation was classified as a missense mutation.

# Artificial Mutation
An artificial single-nucleotide substitution was also introduced into the AR coding sequence.

The codon GAA was changed to GCA at coding sequence position 5. This changes the second amino acid from glutamic acid (E) to alanine (A). Since only one nucleotide was changed, the reading frame remained unchanged.

# Main Results
The documented c.2296G>A mutation caused a missense change from alanine to threonine at amino acid 766. The WT and predicted documented mutant proteins were both 920 amino acids long, and the reading frame remained unchanged.
